### O que faço

- **Arquitetura**: Clean Architecture, DDD, CQRS, eventos de domínio, idempotência e resiliência aplicados a problemas reais, com decisões registradas em ADRs.
- **AI Engineering**: agentes e sub-agents, context engineering, skills, MCP e evals para sistemas não determinísticos.
- **Developer Productivity**: spec-driven development, gates de CI e automação do ciclo de desenvolvimento.
- **Ponta a ponta**: backend, frontend, cloud e DevOps.

### Harness Engineering

`Context → Planning → Skills → Sub-agents → Tools/MCP → Execution → Evals → Observability → Feedback ↺`

Agentes especializados com ferramentas restritas por papel, saída em contrato estruturado e verificação
independente. Exemplo: auditei 89 execuções reais dos meus agentes e corrigi na fonte um desvio de formato
que o orquestrador não conseguia ler.
